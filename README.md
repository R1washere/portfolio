# Vladyslav Riazantsev

Full-stack developer focused on product-facing web apps, clean API design, and
interfaces that are comfortable to use every day.

I work mostly with React, Next.js, TypeScript, Node.js, NestJS and relational
databases. I like owning features end to end: shaping the UI, designing the API,
modeling the data, and keeping the result understandable for the next person who
opens the code.

## Selected Projects

### FlowForge

Workflow automation demo for SaaS and operations-heavy teams.

Built with Next.js, React, NestJS, TypeScript, Prisma and SQLite. It includes a
workflow builder, webhook triggers, scheduled runs, execution logs, RBAC and an
audit trail.

Repository: https://github.com/R1washere/flowforge

### InsightHub

Product analytics demo for B2B SaaS teams.

Built with Next.js, React, NestJS, TypeScript, Prisma and SQLite. It includes
event ingestion, project API keys, dashboard reporting, event exploration,
funnel analytics and a small browser tracking SDK.

Repository: https://github.com/R1washere/insighthub
